# One command installs the whole circuit, every repository at the commit the stack manifest names:
#
#   python3 -m venv .venv && .venv/bin/pip install -r contracts/install-stack.txt
#
# The seven pins below equal contracts/warden-stack.json (tests/test_install_stack.py holds them to it).
# watcher-mcu is not in the manifest: Warden does not verify it, it reads Warden's run record afterwards.
# Its pin here is the commit that was tested with these seven.

# Running Warden on a target also needs pytest in the same environment (it runs the target's own suite):
#     .venv/bin/pip install 'pytest>=8' "numpy==2.4.6; python_version < '3.12'" "numpy==2.5.4; python_version >= '3.12'" matplotlib==3.11.2
